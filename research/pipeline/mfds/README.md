# MFDS 의료기기 수집 파이프라인 — 재활로봇 리서치

의료기기안심책방(emedi.mfds.go.kr)은 웹 검색 화면이고, **같은 데이터의 OpenAPI는
공공데이터포털(data.go.kr)에 있다.** 이 폴더는 그 API로 재활로봇 관련 허가 목록을
수집하는 파이프라인이다.

## 데이터 소스

| API | data.go.kr | 상태 |
|---|---|---|
| **의료기기 품목허가 정보** | [15057456](https://www.data.go.kr/data/15057456/openapi.do) | ✅ 엔드포인트 실재 확인 (`MdeqPrdlstInfoService02/getMdeqPrdlstInfoInq02`, 2026-09-10 — 키 없이 호출 시 SERVICE_KEY_IS_NULL 반환) |
| 의료기기 품목정보 (사용목적·모델 상세) | [15073906](https://www.data.go.kr/data/15073906/openapi.do) | 경로 미확인 — 활용신청 승인 페이지의 참고문서(스펙)에서 확인 후 추가 |
| 의료기기 제조자정보 | [15073897](https://www.data.go.kr/data/15073897/openapi.do) | 〃 |
| 의료기기 제조·수입업 허가정보 | [15057971](https://www.data.go.kr/data/15057971/openapi.do) | 〃 |

제공 필드(품목허가): 품목명 · 품목등급(1~4) · 품목허가번호 · 허가일자 · 품목상태 · 업체명.
한도: 개발계정 일 10,000건, 초당 제한 있음(스크립트에 0.4s 슬립 내장). JSON/XML.

## 키 발급 (1회, ~10분)

1. [data.go.kr](https://www.data.go.kr) 회원가입·로그인
2. [15057456 페이지](https://www.data.go.kr/data/15057456/openapi.do) → **활용신청** (일반적으로 자동승인)
3. 마이페이지 → 인증키 확인 — **Decoding 키** 사용 (반영까지 최대 1시간)
4. `export MFDS_API_KEY='...'` (셸 프로필에 넣거나 실행 시 지정)

## 사용법

```bash
# 키·스펙 동작 확인 (1건)
python fetch_devices.py --probe

# 기본 키워드(보행·재활·외골격·착용·로봇·운동장치)로 수집
python fetch_devices.py

# 업체로 조준 수집
python fetch_devices.py --keywords 보행 --param entp_name=엔젤로보틱스
```

결과: `research/data/mfds/devices_YYYYMMDD.jsonl`(원본) + `.csv`(요약). 데이터는 비커밋.

## 검증 타깃 (수집이 제대로 됐는지 확인용)

수집 결과에 아래가 잡혀야 정상:

- **엔젤로보틱스** — 엔젤렉스 M20 (병원 재활, 2회차·공경철 노트 참고)
- **현대자동차** — X-ble MEX (의료기기 2등급 허가 2023.1, 2회차 자료)
- Cyberdyne HAL 수입 허가 여부 (있다면 흥미로운 발견)

## 리서치 방향 (수집 후)

1. "재활로봇" 품목 지형: 어떤 품목명 분류로 허가되는지 (보행보조/운동장치/착용로봇 등
   실제 분류 체계 역추적) · 등급 분포 · 연도별 허가 추이
2. 업체 지도: 국내 제조 vs 수입, 신규 진입 연도
3. [[2026-09-10-reimbursement-study-design]]과 연결: 허가(식약처) → 수가(심평원)
   파이프라인에서 이 데이터는 **앞단**. 수가 쪽은 별도 트랙(사용자 담당)
4. 품목정보 API(15073906) 추가 시 **사용목적(intended use) 텍스트** 확보 →
   재활로봇 적응증 분석 가능

## 실측 스펙 (2026-09-10 확인)

- 검색 파라미터 = 응답 필드명 그대로 대문자. **`PRDLST_NM`(품목명)만 부분일치 필터 동작**
- `MDEQ_CLSF_NO`·업체명 계열은 필터 안 됨(무시) → 분류별 추출은 키워드 수집 후 로컬 필터
- 응답에 사용목적(`USE_PURPS_CONT`) 포함, **업체명 필드는 없음** → 품목정보 API(15073906) 조인 필요
- 전 품목 213,333건. 1차 수집(키워드 6종) 2,504건 → 분석: [재활로봇 허가 지형](../../notes/2026-09-10-mfds-rehab-robot-landscape.md)
- 재활로봇 품목분류 확정: **A67080.01 로봇보조정형용운동장치** (32건, 전부 3등급 허가)

## 주의

- 초당 제한: 키워드 추가 시 SLEEP 유지
- 수집 데이터는 공공데이터이나, 가공·재배포 시 출처 표기(식품의약품안전처)
